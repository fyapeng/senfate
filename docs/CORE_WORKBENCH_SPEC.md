# 核心总览工作台规格

## 视觉基准

参考图为桌面研究型工作台：顶部导航 82px；左侧认证命盘栏约 278px；右侧审计抽屉约 410px；中央区域承担年度图表和流派切换。界面以白色、细灰边、深墨文字与单一蓝色强调构成，不使用装饰性渐变。

## 信息架构与真实数据映射

| 区域 | 展示内容 | 数据来源 | 行为 |
| --- | --- | --- | --- |
| 顶部导航 | 总览、时间线、流派、规则、排盘计算 | 路由 | 当前路由高亮 |
| 认证命盘栏 | 四柱、出生时区、经纬度、真太阳时、节气、起运、大运方向 | `/api/chart/compile` 的 `result` 与 `certificate` | 点击四柱或大运打开计算说明 |
| 中央标题 | 选中流派、当前流年、当前大运 | `/api/analysis/run` 的 `selectedYear`、`chart.luckCycles` | 流派切换不混合结果 |
| 流派切换 | 传统子平、邵伟华、李涵辰、段氏理象 | `labels`、`trajectory`、`schools` | 切换同年、同命盘下的独立结果 |
| 年度图表 | 一年一根真实 OHLC 蜡烛：open/high/low/close | `trajectory[school]` | 点击蜡烛选择年度并刷新审计抽屉 |
| 年度定位 | 当前选择年度、对应干支、所在大运 | `annual_contexts`、`luckCycles` | 前后年度、时间线深链 |
| 审计抽屉 | 年度结论、原局→大运→流年、触发/未触发规则、来源与警告 | `schools`、`audit.trace`、`audit.stateChain`、规则详情 API | 折叠/展开每一层；链接到规则详情 |

## 图表规则

1. 蜡烛实体从 `min(open, close)` 到 `max(open, close)`；影线从 `low` 到 `high`。
2. `close >= open` 用蓝色空心蜡烛，`close < open` 用蓝色实心蜡烛；不得以统一高度、柱状图或随机数替代。
3. Y 轴固定为年度主题倾向指标的 `[-1, 1]`；X 轴对应接口返回的年度。
4. 选中年度有明确蓝色标记；图例说明该指标不代表概率、价格或现实结果。

## 验收标准

- 用一次真实认证排盘运行后，四派的蜡烛数与返回年度数一致，且读数可由 API 复核。
- 选中某年后，右侧面板显示该年的流派结论和同一次运行的审计 trace。
- 左栏不出现占位圆点或假资料；缺少资料时显示明确的空值或不可用说明。
- 1440px 桌面宽度下三栏同时完整可见；小屏幕折叠为中央工作区优先的布局。
- 不允许把视觉样稿或静态模拟数据写入生产页面。
