# 流派配置与运行规则

SenFate 的目标是可追溯地执行传统八字体系中的推演规则，不把主题贡献解释为现实事件概率。流派配置决定哪些来源规则进入运行时，以及它们在同一主题上的相对采用权重。

## 当前配置

| 配置 | 采用范围 | 用途 |
| --- | --- | --- |
| `integrated-classical` | 七书中所有可执行规则 | 保留现有综合口径，作为默认配置。 |
| `ziping-pattern` | 《子平真诠》《渊海子平》《滴天髓》《千里命稿》 | 月令、格局、制化优先。 |
| `climate-priority` | 《穷通宝鉴》与格局支持来源 | 寒热燥湿先作为结构约束。 |

权重表示该配置内的采用优先级；它不是文本真伪评分，也不是事件发生概率。相同规则家族仍只取一个代表，跨书出处保留为证据，不因重复出现而重复累加。

## 审校机制

每个配置只能读取已整理入运行库的规则；运行库中的每条规则都具有明确条件、时间层与效应。原始抽取语料仅作内部来源整理，不会进入 API、浏览器或推演结果。配置可按 `recordId` 或 `familyId` 停用规则，但不会将未完成结构化的来源材料带入计算。

## 用神推演协议

`senfate-useful-god-projection.v1` 依次收集四类候选：

1. 已成立格局提出的结构候选；
2. 寒热燥湿提出的调候候选；
3. 日主强弱提出的扶抑候选；
4. 已成化关系提出的通关候选。

候选保留来源、分数和冲突。若平衡向量将某元素列为回避方向，或多个高优先候选接近，结果标为 `contested`，不会强行给出唯一用神。该协议是公开的计算口径，可在未来由具体流派配置替换或细化。
