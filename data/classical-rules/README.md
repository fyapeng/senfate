# SenFate 古籍来源语料 v4.0

本目录保存由七本 TXT 自动抽取得到的 37,231 条结构化来源记录。该文件是来源传输格式，不是运行规则库，也不包含执行等级、产品权重或事件概率。

## 规模

- 图书：7；
- 语义片段：15,967；
- 来源记录：37,231；
- 规则家族：11,306。

## 文件

- `classical-source-corpus.v4.0.json.gz`：来源记录、枚举、条件字典、术语字典和家族索引；
- `manifest.json`：编码、规模、字节数和校验值；
- `enums.json`：人工查看用枚举表。

来源记录只供离线整理。重复来源保留 provenance，但不产生重复模型作用。

## 运行规则库

- `classical-runtime-program.v1.json.gz`：唯一由 API、浏览器和推演引擎读取的规则库；
- `runtime-program.manifest.json`：运行规则库的条数、字节数和校验值。

运行规则库只收录具备明确机器条件、时间层和效应的规则。未能完成这种转写的来源记录不会出现在产品界面、接口返回或计算路径中。

## 边界

语料描述传统八字文献内部的命题与推断方式。自动抽取置信度只描述结构化可靠度，不决定运行资格、优先级、作用大小或现实预测效度。
